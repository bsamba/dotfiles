# Issue tracker

Specs and tickets live in GitHub Issues for `bsamba/dotfiles`. Use `gh` with
`--repo bsamba/dotfiles` explicitly.

Publish specs and approved implementation tickets as separate issues labelled
`ready-for-agent`. Link tickets to their spec as sub-issues. Record actual blocking
dependencies with native GitHub issue dependencies; use a `Blocked by` list when
native dependencies are unavailable.

PRs as a request surface: no.

Keep repository-specific workflow configuration here: the root `AGENTS.md` is
hardlinked to machine-wide instructions and must remain repository-independent.
